# URL Shortener

Dockerized URL shortener API built with Node.js, TypeScript, Express, PostgreSQL, Docker Compose, GitHub Actions, and Docker Hub deployment.

## Phase 0

- Set up the project scaffold
- Install dependencies
- Add the first health check endpoint
- Prepare the Docker and CI/CD foundation

## Phase 2

- Add a container image for the API
- Run PostgreSQL and the app with Docker Compose
- Make the app boot with database-backed storage inside containers

## Run with Docker Compose

```bash
docker compose up --build
```

Open:

```text
http://localhost:3001
```
